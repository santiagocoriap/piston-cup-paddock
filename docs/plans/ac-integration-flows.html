How the AC integration works

The goal: a race night needs no upload and no typing. The data goes from the AC server and from each driver to the app by itself. The admin only checks problems and approves the official result.

  • 0 programs for drivers to open
  • 1 click for the admin before the race
  • 1 click for the admin after the race

Words in this page

Paddock appThe website of the league. It keeps results, standings, and laps.
Server programpaddock-collector.exe. It runs on the PC of the AC server. It sends files and events to the app, and writes the race setup into the server.
Paddock scriptA small Lua script. The league server sends it into AC when a driver joins. It runs inside the game and sends each lap to the app.
KeyA secret password for the server program. The app shows it one time only.
Race codeA new secret for each race. The app makes it, the server gives it to the drivers on the server, and the script sends it with each lap.
CSPCustom Shaders Patch. A free add-on for AC. The league server already needs it.

1. Admin: connect the AC server to the app

The admin does this one time. After this, the server program starts by itself with Windows.

    C --> D["Click 'Crear clave'.<br/>The key is a secret password for the server PC"]
    D --> E["Click 'Descargar colector'.<br/>You get a zip: the program + a settings file with the key inside"]
    E --> F["Copy the zip to the PC that runs the AC server, and unzip it"]
    F --> G["Run paddock-collector.exe --setup"]
    G --> H["The program asks 2 things:<br/>1. Where is the AC server folder?<br/>2. What is the public address and port of the server?"]
    H --> I{"The program calls the app:<br/>'Is my key good?'"}
    I -- No --> J["The screen says what is wrong.<br/>Fix the key or the address"]

    K --> L["In Content Manager, add the extra plugin 127.0.0.1:6973.<br/>Now the program hears the race live"]

    M --> N(["Done. In 'Colectores' the server shows a green dot: 'Conectado'"])

How the app trusts a lap

A driver has no key for the script. These checks replace the key:

  1. The lap has the race code of tonight. Only drivers on the league server get this code.
  2. The server program says that this Steam ID was on the server at that time.
  3. The lap time is inside a league session, and the track and the car are the same.
  4. If one point fails, the app does not keep the lap.

Phase 0 result: the idea works

  • Checked: Phase 0 test, October 14, 2026: AC loaded the script from the server with no click from the driver.
  • Checked: The script sent the start message and each lap to a receiver with web.post.
  • Checked: The script read the Steam ID of the driver and the race code from the server options.

Open questions

  3. Does Real Penalty 'Seconds penalty to final time' change the total time in the result file?
  4. Is the Windows SmartScreen warning on the server PC acceptable, or do we buy a code signing certificate?
